# Tiny Todo API

Tiny Todo API — это небольшой REST API сервис для управления задачами (todo), написанный на Go.
Проект создан как учебный, но постепенно развивается в более полноценный backend-сервис.

Главная цель проекта — исследование и применение различных подходов к построению backend-приложений на Go.
